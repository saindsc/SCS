🏗️ DATA STRUCTURE
=================

BlogPost Object:
```
{
  id: number
  slug: string (URL identifier)
  title: string (Article title)
  excerpt: string (Short summary)
  content: string (Full article - markdown-style)
  author: string (Writer name)
  authorRole: string (Credentials)
  date: string (YYYY-MM-DD)
  readTime: string ("X min read")
  category: string (mental-health | relationships | wellness | parenting | self-care)
  tags: string[] (Topic tags)
  image: string (Path, URL, or emoji)
  additionalImages?: string[] (Gallery images)
  featured: boolean (Show on featured section)
}
```

🛠️ HOW TO ADD NEW ARTICLE
==========================

Step 1: Create content and gather info
- Write article in markdown-style format
- Gather author name and credentials
- Create/select feature image
- Write excerpt (150-200 chars)
- Estimate read time (250 words/min)
- Select category
- Create URL-friendly slug

Step 2: Add to blog-data.ts
```typescript
{
  id: 7,
  slug: 'your-article-slug',
  title: 'Your Article Title',
  excerpt: 'Brief summary of article...',
  content: `Your article content...

  ## Section Heading

  Paragraph text here...

  - Bullet point
  - Another point
  `,
  author: 'Author Name',
  authorRole: 'Role/Credentials',
  date: '2026-04-12',
  readTime: '5 min read',
  category: 'wellness',
  tags: ['tag1', 'tag2', 'tag3'],
  image: '/images/article-image.png',
  featured: false,
}
```

Step 3: Upload image
- Save to /public/images/[name].png
- Use local path in image field

Step 4: Test
- Navigate to /blog to verify listing
- Click article to verify detail page
- Test on mobile and desktop

🎯 FILTERING LOGIC
==================

Category Filter (case-insensitive):
```
if (selected === "all") → show 6 articles
if (selected === "mental-health") → show articles where category = "mental-health"
if (selected === "wellness") → show articles where category = "wellness"
if (selected === "relationships") → show articles where category = "relationships"
```

Filtering Algorithm:
1. Normalize selection: trim().toLowerCase()
2. Compare with post.category.trim().toLowerCase()
3. Return matching posts or all if "all"

🐛 COMMON ISSUES & SOLUTIONS
=============================

Issue: Article not showing in featured section
→ Solution: Set featured: true in blog-data.ts

Issue: Image not displaying
→ Solution: Use local path /images/... or full URL with http://
→ Fallback: Use emoji instead

Issue: Category filter not working
→ Solution: Ensure category value in article matches exact category id
→ Make sure to refresh page

Issue: Content formatting looks wrong
→ Solution: Check markdown-style format follows rules (## for h2, ### for h3, etc.)

Issue: Content not rendering
→ Solution: Check for syntax errors in JavaScript (quotes, brackets, etc.)
